🚀 بازی دورهمی سایبرپانکی H.O.P.E (بحران در سفینه امید)

یک بازی نقش‌آفرینی، تعاملی و مبتنی بر وب (تک‌صفحه‌ای) طراحی‌شده با React 18 و استایل‌دهی Tailwind CSS. این بازی با اتمسفر علمی‌تخیلی و سایبرپانکی خود، پلتفرمی فوق‌العاده برای ایجاد مشورت، کار تیمی چالش‌برانگیز و معماهای هیجان‌انگیز در دورهمی‌های ۲ تا ۱۶ نفره است.

🎭 ویژگی‌های برجسته بازی

حالت همکاری (Co-op): همه بازیکنان خدمه یک سفینه فضایی آسیب‌دیده هستند که منابع حیاتی آن (اکسیژن، بدنه، روحیه) لحظه به لحظه در حال کاهش است.

تضاد منافع رقابتی: استفاده از هر تخصص به بازیکنان امتیاز فردی می‌دهد، اما لزوماً همیشه بهترین گزینه برای بقای سفینه نیست. این تضاد، ریشه اصلی تعامل و بحث‌های داغ گروه است!

پشتیبانی تا ۱۶ بازیکن: تخصیص خودکار نقش‌های تخصصی (پزشک، مهندس، فرمانده، دانشمند، خلبان، سرباز، تکنسین، روانشناس) بر اساس تعداد نفرات.

پازل‌های تعاملی و ابزار چرکنویس گروهی: در دورهای ۳ و ۷، بازیکنان باید با کمک چرک‌نویس دیجیتالِ روی مانیتور و کیپد فیزیکی، رمزهای عبور را به صورت چپ به راست وارد کنند.

پلات توییست عمیق داستانی: در دور دهم، هویت واقعی سیستم H.O.P.E افشا شده و بازیکنان در برابر یک دوراهی اخلاقی سخت (انتخاب قطعی بدون تاس شانس) قرار می‌گیرند.

افکت‌های صوتی فضایی (Web Audio API): صداگذاری و بوق‌های هشدار/موفقیت در بخش معماها کاملاً به صورت محلی و با فرکانس‌های سینت تولید می‌شوند.

🛠️ راهنمای سریع راه‌اندازی روی GitHub Pages

از آنجایی که این بازی به صورت Single File (تک‌فایلی) نوشته شده است، راه‌اندازی آن روی گیت‌هاب تنها چند دقیقه طول می‌کشد و نیاز به هیچ سرور یا پیش‌نیازی ندارد:

وارد اکانت GitHub خود شوید و یک ریپازیتوری جدید (مثلا به نام hope-game) بسازید.

فایل index.html موجود در این پروژه را دقیقاً در ریشه (Root) مخزن خود آپلود کنید.

فایل README.md را نیز در ریشه مخزن آپلود کنید.

وارد بخش Settings ریپازیتوری خود شوید.

از منوی سمت چپ، روی گزینه Pages کلیک کنید.

بخش Build and deployment را روی شاخه اصلی (مثلاً main یا master) و پوشه / (root) تنظیم کرده و روی Save کلیک کنید.

پس از یک دقیقه، آدرس اختصاصی گیت‌هاب شما فعال می‌شود و می‌توانید لینک بازی را برای دوستانتان بفرستید!
